# PandasLab · 可视化数据分析工作台

> 《可视化导论》课程作业 —— 在浏览器里运行**真实的 pandas**，用鼠标做数据分析，操作即生成代码。

一个无需安装 Python 环境的数据分析工具。打开网页就能载入数据、清洗、变换、聚合、出图，
而每一步鼠标操作都会**实时生成对应的 pandas 代码**——这段代码不是"翻译"，**就是实际在执行的那段**，
复制到 Jupyter 能原样跑出相同结果。

## 核心特性

| 特性 | 说明 |
|---|---|
| **真 pandas 引擎** | 通过 Pyodide 在浏览器 WebAssembly 里运行 pandas 2.2，不是 JS 模拟 |
| **65 项操作** | 覆盖读取、概览、筛选、排序、清洗、派生、聚合、重塑合并、时间序列、文本处理九大类 |
| **管道式交互** | 操作串成可拖拽重排、可单步停用、可中途插入的卡片链，改任意一步下游自动重算 |
| **代码即执行** | 右侧实时生成完整 pandas 脚本，可复制、可下载 `.py` |
| **自动荐图** | 按所选列的类型自动推荐合适的图表（直方图/箱线图/散点/分组条形/热力图…） |
| **一键数据体检** | 整体概况 + 每列画像 + 缺失值矩阵 + 相关性热力图 |
| **中英双语** | 360 条词条完全对称，界面、操作名、字段、选项、提示全覆盖 |

## 两个关键的工程设计

### 1. Pyodide 很慢，但用户不该感知到慢

Pyodide 首次加载约 20 秒。直接等待会毁掉交互体验，因此采用双阶段策略：

1. 页面打开后**立刻**用轻量 JS 解析器渲染默认数据集 —— 实测 **60 毫秒**表格可见、可滚动、可看列统计
2. Pyodide 在 Web Worker 里后台加载，右上角有可见进度
3. 引擎就绪后自动接管，用真实 dtype 与统计量覆盖预览期的推断值

| 指标 | 首次访问 | 第二次（浏览器缓存） |
|---|---|---|
| 表格可见 | ~1.5 秒 | **0.06 秒** |
| 引擎就绪 | 20.7 秒 | **3.6 秒** |

计算全部跑在 Worker 里，因此**重算时界面永不冻结**。

### 2. 管道记忆化：改第 5 步不重算前 4 步

每步带一个"前缀哈希"，标识执行完该步之后的数据帧状态。只要前缀未变，Python 侧直接复用缓存。

20 万行 × 6 列实测（筛选 + 排序 + 双键分组）：

| 场景 | 耗时 |
|---|---|
| 首次执行（冷） | 57 ms |
| 完全相同（全缓存命中） | **4 ms** |
| 只改末步（前两步命中缓存） | **13 ms** |
| 改首步（全部重算） | 61 ms |

这就是管道能随意拖拽重排、实时改参数却依然流畅的原因。

## 技术栈

- 原生 HTML / CSS / JavaScript（ES Modules），**无框架、无构建步骤**
- [Pyodide](https://pyodide.org/) 0.26 + pandas 2.2 + NumPy（从 jsDelivr CDN 按需加载）
- [Apache ECharts](https://echarts.apache.org/) 5（本地内置）

> ⚠️ **需要联网**：分析引擎（Pyodide + pandas，约 30 MB）从 CDN 加载，首次访问后会被浏览器缓存。
> 若需完全离线，可把 Pyodide 自托管到 `assets/vendor/pyodide/` 并修改 `worker.js` 顶部的 `PYODIDE_BASE`。

## 本地运行

页面通过 `fetch` 读取数据集，直接双击 `index.html` 会被浏览器同源策略拦截，需启动本地服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 目录结构

```
.
├── index.html              页面结构
├── styles.css              全部样式
├── app.js                  主程序：状态编排、管道 UI、检视面板
├── worker.js               Pyodide Worker：pandas 执行、图表聚合、数据体检
└── assets/
    ├── js/
    │   ├── engine.js       与 Worker 的 RPC 封装
    │   ├── pipeline.js     管道状态、前缀哈希、撤销重做
    │   ├── ops.js          65 项操作的参数结构与代码生成
    │   ├── opform.js       操作选择器与参数表单（由 ops 声明驱动）
    │   ├── charts.js       自动荐图与 ECharts option 构造
    │   ├── table.js        虚拟滚动表格
    │   ├── csv.js          轻量 CSV 解析（秒开预览用）
    │   └── i18n.js         中英双语字典（360 条）
    ├── datasets/           4 份内置数据集
    └── vendor/             ECharts
```

## 已知限制

- 分析引擎需联网加载（见上文技术栈说明）
- 表达式字段（`query` / `assign`）使用 pandas 自身的表达式解析器；`apply` 允许任意 lambda，
  因为全部运行在用户自己浏览器的沙箱内、处理用户自己的数据，不涉及服务端执行
- 超大文件（百万行以上）受浏览器内存限制，建议先抽样
